Immuta Custom Restful Catalog API

A RESTful API for managing data catalogs, tags, and data sources

About the Project

This project provides a custom Restful Catalog API for Immuta, allowing users to manage data catalogs, tags, and data sources. It is built using Netlify Functions, providing a serverless architecture that is easy to deploy and scale.

The API supports the following features:

  • Manage data catalogs
  • Manage tags for data classification
  • Manage data sources
  • Associate tags with data sources
  • Complete API endpoints for Immuta integration

Getting Started

Prerequisites

  • Git
  • A Netlify account (for deployment)

Deployment

# Clone the repository
git clone https://github.com/1126844947/test-immuta-project.git

# Navigate to the project directory
cd test-immuta-project

# Deploy to Netlify
# 1. Sign up for a Netlify account at https://www.netlify.com/
# 2. Connect your GitHub repository to Netlify
# 3. Netlify will automatically deploy the site

API Documentation

Health Check

  • GET /health

    Returns the health status of the API

Tag API

  • GET /tags

    Returns all tags

  • GET /api/tags

    Returns all tags

DataSource API

  • POST /dataSource

    Returns data source metadata

  • POST /api/dataSource

    Returns data source metadata

  • GET /dataSource/page/{id}

    Returns data source page metadata

  • GET /api/dataSource/page/{id}

    Returns data source page metadata

Testing

To test the API endpoints, use the following commands:

# Test health check
curl https://your-site.netlify.app/health

# Test tags endpoint
curl https://your-site.netlify.app/tags

# Test dataSource endpoint
curl -X POST https://your-site.netlify.app/dataSource

# Test dataSource page endpoint
curl https://your-site.netlify.app/dataSource/page/customer_db

Deployment

Using Netlify

This project is deployed using Netlify Functions, which provides a serverless architecture:

  • Serverless: No need to manage servers
  • Auto-scaling: Automatically scales with traffic
  • Continuous deployment: Automatically deploys when you push to GitHub

To deploy your own instance:

1. Fork the repository on GitHub
2. Sign up for a Netlify account
3. Connect your forked repository to Netlify
4. Netlify will automatically deploy the site
5. Get your site URL from Netlify dashboard
