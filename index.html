Immuta Custom Restful Catalog API

A RESTful API for managing data catalogs, tags, and data sources

About the Project

This project provides a custom Restful Catalog API for Immuta, allowing users to manage data catalogs, tags, and data sources. It is built using Node.js and Express framework, following RESTful API design principles.

The API supports the following features:

  • Manage data catalogs
  • Manage tags for data classification
  • Manage data sources
  • Associate tags with data sources
  • Complete CRUD operations for all resources

Getting Started

Prerequisites

  • Node.js (v14.0.0 or higher)
  • npm (v6.0.0 or higher)

Installation

# Clone the repository
git clone https://github.com/1126844947/test-immuta-project.git

# Navigate to the project directory
cd test-immuta-project

# Install dependencies
npm install

# Start the server
npm start

Environment Configuration

The server port can be configured in the .env file:

# Server Configuration
PORT=3001

# Environment
NODE_ENV=development

# CORS Configuration
CORS_ORIGIN=*

API Documentation

Health Check

  • GET /health

    Returns the health status of the API

Catalog API

  • GET /api/catalog

    Returns all data catalogs

  • GET /api/catalog/:id

    Returns a single data catalog by ID

  • POST /api/catalog

    Creates a new data catalog

  • PUT /api/catalog/:id

    Updates an existing data catalog

  • DELETE /api/catalog/:id

    Deletes a data catalog

Tag API

  • GET /api/tags

    Returns all tags

  • GET /api/tags/:id

    Returns a single tag by ID

  • POST /api/tags

    Creates a new tag

  • PUT /api/tags/:id

    Updates an existing tag

  • DELETE /api/tags/:id

    Deletes a tag

DataSource API

  • GET /api/data-sources

    Returns all data sources

  • GET /api/data-sources/:id

    Returns a single data source by ID

  • POST /api/data-sources

    Creates a new data source

  • PUT /api/data-sources/:id

    Updates an existing data source

  • DELETE /api/data-sources/:id

    Deletes a data source

  • POST /api/data-sources/:id/tags

    Adds a tag to a data source

  • DELETE /api/data-sources/:id/tags/:tagId

    Removes a tag from a data source

Testing

To run the tests, use the following command:

npm test

The test suite includes tests for all API endpoints, ensuring they work as expected.

Deployment

Using ngrok for Public Access

To make the API publicly accessible, you can use ngrok:

# Install ngrok globally
npm install -g ngrok

# Start ngrok on the port your server is running
ngrok http 3001

ngrok will provide a public URL that you can use to access your API from anywhere.
